# Freyr Phase 0+1 Implementation Plan (SvelteKit/SQLite)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the Freyr SvelteKit app and ship the transaction ledger, monthly/yearly
budget views, and the one-time Excel seed import — replacing the Monthly, Yearly, and
Budget-% sheets of `Finances v2.xlsx`.

**Architecture:** SvelteKit 2 (Svelte 5, TypeScript, `adapter-node`), server-rendered with
form actions + `use:enhance`. Domain logic in `src/lib/server/*`; `+page.server.ts` thin.
SQLite via stdlib `node:sqlite` (`DatabaseSync`) — no native addons. Money is integer paise;
percentages integer basis points; derived values computed at read time.
Spec: `docs/superpowers/specs/2026-07-18-freyr-v1-design.md`.

**Tech Stack:** Node ≥ 22.13 (installed: 22.14), SvelteKit 2 + Svelte 5, `node:sqlite`,
`bcryptjs`, `exceljs`, `tsx` (dev), Vitest, svelte-check, Prettier + ESLint.

## Global Constraints

- **Money is never a float.** Integer paise via `src/lib/money.ts`; basis points for
  percentages (27.20% → 2720). Division only through explicit rounding helpers. The importer
  parses cell values with integer/string math. SQLite `CHECK` constraints back every invariant.
- Currency: **INR only**; format `₹1,23,456.78` (Indian grouping; whole rupees omit decimals).
- Derived values are **computed, never stored**.
- Domain logic in `src/lib/server/*`; `+page.server.ts` thin (parse → domain → return).
- SQLite pragmas on every open: `journal_mode=WAL`, `busy_timeout=5000`, `foreign_keys=ON`.
- Dates: `TEXT` `YYYY-MM-DD` in SQLite; plain `string` dates in TS domain code (no Date
  timezone traps); `src/lib/money.ts` stays dependency-free.
- Conventional Commits, imperative, lowercase. **No co-author trailers.**
- Every task ends with `npm run lint` + `npm run check` + `npm test` clean.
- `Finances v2.xlsx` is personal data: **git-ignored, never committed**. Tests use a
  synthetic fixture built in-test with exceljs.
- Executor environment is Windows/PowerShell.

### Task 3: `src/lib/server/db` — open + migrations
